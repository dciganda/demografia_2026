# Demografía 2026

Bienvenidas y bienvenidos al curso **Demografía (337N)** de la Licenciatura en Estadística, correspondiente al segundo semestre de 2026.

Durante el curso se presentan las principales herramientas del análisis demográfico, sus modelos y las fuentes de datos utilizadas para estudiar los procesos demográficos. Las clases combinan exposición teórica y laboratorios en R.

## Materiales

Los materiales se publican progresivamente antes de cada clase. Para obtener el repositorio por primera vez:

```powershell
git clone https://github.com/dciganda/demografia_2026.git
cd demografia_2026
```

Para descargar nuevas clases posteriormente:

```powershell
git pull
```

Las diapositivas, los laboratorios y los datos estarán organizados dentro de `materiales/`. Las pautas y otros recursos de evaluación que correspondan se publicarán en `evaluaciones/`.
